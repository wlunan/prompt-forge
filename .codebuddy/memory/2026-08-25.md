## 点击提示词的条件显示逻辑
- 需求：点击提示词时判断是否含变量；无变量隐藏「填写变量」区域，全部空间展示内容；有变量正常显示填写页面
- 实现：改造 `FillPanel.vue` 自适应布局
  - 左侧表单 `div.fill-form` 加 `v-if="variables.length > 0"`，无变量时隐藏
  - `.fill-body` 加动态 class `single`（`variables.length === 0` 时），切换为单列 grid `grid-template-columns: 1fr`
  - 移除不再引用的 `.no-vars` 死样式
- 判断逻辑：`variables = computed(() => props.unit?.variables || [])`，准确识别变量存在性（含 undefined 兜底）
- 点击流程不变：`PromptList @activate` → `selectActive()` → `phase='fill'` → FillPanel 自适应
- 构建通过（80 模块）

## 备注
- 键盘 Enter 键对无变量提示词仍为「直接复制」（未改动），点击则进入纯预览模式，两者行为有差异但均合理
